# ChemCorp Industries — B2B Chemical Ordering Platform

Full-stack B2B storefront for a chemical distribution group: **15 subsidiary brands, 360 placeholder products**, bulk ordering with GST-ready checkout, an admin dashboard, and an automated **end-of-day email report** of all orders.

Built with Next.js 16 (App Router) · Tailwind v4 · Postgres (pg) · Nodemailer.

**Live:** https://chemcorp.onrender.com (Render) · https://chemcorp.vercel.app (Vercel) — both share one Render Postgres database.

## Quick start

```bash
npm install
cp .env.example .env   # set DATABASE_URL (any Postgres works)
npm run dev            # http://localhost:3000
```

The schema is created and seeded automatically on first request (15 brands × 24 SKUs).

The daily-report scheduler runs **inside the server** (`instrumentation.ts`) — no second process needed. It checks every minute and sends once per day after the configured hour (deduped via the `report_log` table, so restarts don't double-send). A standalone `npm run scheduler` also exists if you ever run the app somewhere the embedded scheduler is disabled (`DISABLE_EMBEDDED_SCHEDULER=1`).

## What's inside

| Route | Purpose |
|---|---|
| `/` | Landing page — hero, brand grid, featured products |
| `/brands`, `/brands/[slug]` | The 15 subsidiaries and their product lines |
| `/products` | Full catalog: search, brand & category filters, pagination |
| `/products/[slug]` | Product detail + add to cart (MOQ enforced) |
| `/cart` → `/checkout` | Cart and B2B checkout (company, GSTIN, notes) |
| `/order/[orderNumber]` | Order confirmation |
| `/admin` | Orders table, stats, report settings, "Send report now" |

**API:** `POST /api/orders` · `GET/PUT /api/settings` · `POST|GET /api/report/send`

## Daily email report

Every order placed during the day is rolled into one **formatted HTML email** — orders count, revenue, units, per-brand breakdown, top products, and full order-by-order detail with customer notes — sent automatically at end of day.

- **Recipient:** change anytime in **Admin → Report settings** (stored in DB, defaults to `yuvraajbhatter10@gmail.com`).
- **Send time:** also configurable in Admin (default 18:00).
- **Manual trigger:** Admin → "Send today's report now", or `curl -X POST localhost:3000/api/report/send`.
- **No SMTP configured?** The report is saved to `./reports/*.html` so you can preview it in a browser. Every run is logged in Admin → "Recent report runs".

## Deployments

Pushing to `main` auto-deploys **both** hosts (Render via its GitHub integration, Vercel via its Git connection).

- **Render** (`chemcorp.onrender.com`): runs `npm start`; the embedded scheduler (`instrumentation.ts`) sends the daily report. Free instance sleeps when idle — the Vercel cron still covers the report either way.
- **Vercel** (`chemcorp.vercel.app`): serverless; the daily report fires via Vercel Cron (`vercel.json`, 12:30 UTC = 18:00 IST) hitting `/api/report/send` with `CRON_SECRET`.
- **Database**: Render Postgres `chemcorp-db` (Singapore), shared by both. ⚠️ Free Postgres expires **15 Aug 2026** — upgrade the instance or migrate before then.
- **Admin auth**: `/admin`, `/api/settings` and the order-list API require Basic auth (user `admin`, password in the `ADMIN_PASSWORD` env var on both hosts) whenever that var is set.

## Swapping in the real catalog

All placeholder data lives in `lib/seed-data.ts` (brand names, taglines, colors, chemical lists). Replace it with the client's real list, then `TRUNCATE brands, products RESTART IDENTITY CASCADE` (or point at a fresh database) and restart — the app reseeds itself. Placeholder artwork is generated by `components/product-image.tsx`; replace with `next/image` + real photos when available.
